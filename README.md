# ⚡ AlphaForge

[![Python](https://img.shields.io/badge/Python-3.11+-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://python.org)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.35+-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://streamlit.io)
[![License](https://img.shields.io/badge/License-MIT-FFD700?style=for-the-badge)](LICENSE)

AlphaForge is a modular quantitative trading research platform for backtesting systematic strategies, analyzing portfolio risk, and simulating probabilistic market scenarios — built with Python, Streamlit, Pandas, NumPy, Plotly, and SQLite across a six-tab institutional-grade interface covering strategy backtesting, portfolio construction, multi-strategy comparison, factor exposure analysis, stress testing, forward validation, Monte Carlo simulation, and professional tear sheet generation across a searchable universe of 400+ assets.
